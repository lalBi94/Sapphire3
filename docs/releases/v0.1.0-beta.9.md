# Sapphire 3 — 0.1.0-beta.9

Bêta centrée sur le **Plugin SDK**, la configuration des entrées natives et l’organisation du menu de création. Le format workspace reste en version 3 ; aucune migration supplémentaire n’est introduite.

## Nouveautés

- **Plugin SDK local** : package `@sapphire3/plugin-sdk`, manifeste déclaratif `.sp3plugin`, validation, permissions, dépendances, conflits et cycle de vie. Gestionnaire **Settings → Plugins** avec import local, activation, désactivation et désinstallation.
- **Widgets de plugin** : renderer déclaratif, propriétés, état persistant, entrées liées à une variable, sorties liées à une fonction `(T) -> void`, slider et bouton. La carte bascule entre le widget et sa définition JSON en lecture seule ; les liaisons produisent des flèches de dépendance depuis les modules fournisseurs.
- **Opérations natives de plugin** : opérations typées, validation, pureté/effets, implémentation par expression sûre et émetteurs JavaScript/Python optionnels. Refus explicite si un backend manque.
- **Composites de niveau A** : insertion atomique d’un brouillon natif avec des trous à remplir. Les nœuds sémantiques de niveau B restent hors périmètre.
- **Dashboard exporté** : widgets de plugin, définitions, manifestes actifs et opérations natives embarqués ; variables et callbacks résolus dans le run borné et le live. Un plugin absent produit un panneau de diagnostic sans retirer les données.
- **Configuration des entrées natives** : les sélecteurs de fonction des boutons toggle/hold, des entrées `int`/`float`/`string` et des sélecteurs RGB/RGBA sont regroupés dans un volet **Configuration** pliable, replié par défaut.
- **Menu de création** : quatrième colonne **Plugins** à droite lorsque des widgets de plugin sont disponibles. Les sous-catégories de **Widgets** sont repliées par défaut ; **Entrées** est divisée en **Boutons**, **Nombres**, **Texte** et **Couleurs**.
- **Documentation** : `docs/sdk/plugin-sdk.md`, `docs/PLUGIN_CAPABILITIES.md`, pages du wiki et site public mis à jour.

## Installation

- **Windows** : `Sapphire3-0.1.0-beta.9-windows-setup.exe` ou `Sapphire3-0.1.0-beta.9-windows.zip`.
- **Linux x64** : `Sapphire3-0.1.0-beta.9-linux-x64.tar.gz`, puis `./Sapphire3`. WebKitGTK 4.1 requis.
- **Linux ARM64** : `Sapphire3-0.1.0-beta.9-linux-arm64.tar.gz`.
- **macOS** : `Sapphire3-0.1.0-beta.9-macos-universal.zip`, puis `Sapphire 3.app`. macOS 11 ou ultérieur requis.

## Compatibilité et limites

- Workspace version 3 inchangé ; les fichiers versions 1 et 2 sont toujours migrés à la lecture.
- Les plugins restent **déclaratifs** : pas de composant React ou JavaScript tiers, pas de HTML, pas de marketplace, pas de backend distant.
- Les permissions fichiers, réseau et API native sont déclarées mais refusées (`PLUGIN_PERMISSION_UNSUPPORTED`).
- Les paquets **Linux et macOS sont construits mais n’ont pas été exécutés** sur leur système cible. Leur prise en charge réelle doit être vérifiée avant d’être annoncée comme validée.
- Windows n’est pas signé et macOS n’est pas notarié : des avertissements système peuvent apparaître. Aucun certificat n’est configuré.
- L’installateur Windows est construit ; l’installation et la désinstallation n’ont pas été rejouées pour cette bêta. Le lancement vérifié concerne le ZIP portable extrait.
- C, C++ et Java restent indisponibles ; les cartes graphiques et les classes ne sont pas transpilées.
