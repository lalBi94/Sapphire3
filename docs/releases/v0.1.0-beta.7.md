# Sapphire 3 — 0.1.0-beta.7

## Nouveautés

- Export Web Dashboard : fichier HTML autonome, moteur réel, sept widgets, Run/Pause/Stop, sortie et exécution courante.
- Navigation dans la trace par clic sur la progression (pause immédiate) et vitesse réglable par curseur ×1–×100.
- Interface traduisible dans les huit langues de l'application, thèmes clair/sombre, panneaux déplaçables, redimensionnables et masquables ; préférences conservées dans le navigateur.
- Écran agrandi automatiquement avec recadrage, cartes sans halo, icônes et confirmations visuelles ; pied de page avec logo, version, Threadlock Systems et lien GitHub.
- Spirograph et Pendulum wave produisent désormais plusieurs images animées.
- Sidecar Discord Rich Presence migré de Go vers C++20, sans runtime supplémentaire chez l'utilisateur.

## Compatibilité et limites

- Workspace version 3 inchangé ; aucune migration supplémentaire.
- Les noms saisis et les sorties ne sont pas traduits ; le genre du nœud courant dans le dashboard reste dans la langue d'export.
- Linux x64/ARM64 et macOS universel : paquets construits, non testés à l'exécution sur leurs systèmes cibles. Installation des mises à jour manuelle sur ces plateformes.
- Sans certificat configuré, les binaires Windows ne sont pas signés et macOS n'est pas notarié. Des avertissements système peuvent apparaître.
- Installateur Windows fourni ; installation/désinstallation non rejouées pour cette bêta. Le lancement Windows vérifié concerne le ZIP portable extrait.

## Vérifications de cette bêta

- 585 tests Node/Python réussis ; tests C++ du sidecar, faux IPC Discord et fonctionnement sans Discord réussis.
- Build de production et quatre archives contrôlés : ressources sans sources ni fixtures, licences présentes, permissions Unix et architectures Linux vérifiées.
- Application Windows extraite du ZIP lancée : chaîne application → sidecar → IPC validée.
- Pas de nouvelle campagne exhaustive des dialogues natifs, de l'accessibilité ni des systèmes Linux/macOS.

Cette version est une préversion bêta.
