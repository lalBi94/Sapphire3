# Sapphire 3 Beta 0.1.0-beta.4

Nouvelle bêta Windows, centrée sur le **mode exercice**, l’enrichissement du catalogue et la préparation d’une distribution institutionnelle. Le format workspace reste en version 2 ; aucune migration supplémentaire n’est introduite.

## Nouveautés

- **Mode exercice local** : un `.sp3` peut contenir un manifeste `exercise` avec consignes, snapshot de départ, tests d’entrée ou de fonction. **Check** exécute les tests dans le Web Worker, affiche l’attendu et l’obtenu, et **Reset to starter** restaure le squelette. Le robot réagit au résultat.
- **Protection d’exercice** : mot de passe optionnel stocké sous forme d’empreinte **PBKDF2-SHA256** (sel, 150 000 itérations). Verrou d’interface uniquement : le `.sp3` n’est pas chiffré.
- **Solutions** : quand tous les tests passent, **Save solution** enregistre une copie `<titre>-solution.sp3`, sans changer le fichier courant. Le dossier de ces fichiers sert de banque de corrections.
- **Dix nouveaux exemples** avec widgets : Euclide, recherche dichotomique, crible des nombres premiers, tri par insertion, histogramme de dés, file de caisse, thermostat, ressort amorti, remplissage par propagation et triangle de Pascal.
- **Catalogue de 46 exemples** : difficultés revues, répartition Simple 6 / Medium 23 / Hard 17.
- **Distribution** : licence MIT, installateur Windows par utilisateur, métadonnées de l’exécutable et chaîne de signature Authenticode prête. **Aucun certificat n’est fourni** ; le paquet publié est non signé.
- **Accessibilité** : audit axe-core sur le canvas, les menus, les propriétés, la simulation, les exercices et les paramètres ; corrections de contraste, de titres, de libellés et de zones défilables.
- **Documentation** : wiki du projet et pages `abstract/` actualisées.

## Installation et mise à jour

1. Télécharger `Sapphire3-0.1.0-beta.4-windows.zip` ou `Sapphire3-0.1.0-beta.4-windows-setup.exe`.
2. Pour le ZIP : extraire dans un dossier accessible en écriture, puis lancer `Sapphire3.exe`.
3. Pour l’installateur : installation par utilisateur, sans droit administrateur.

Windows 10/11 avec WebView2 est requis ; Node.js n’est pas nécessaire. La mise à jour intégrée propose cette préversion après publication, avec confirmation et vérification de la taille et du SHA-256.

> Le paquet est **non signé** : SmartScreen peut afficher un avertissement. Ne pas le présenter comme une version signée.

## Limites connues

- Version **bêta**.
- Les tests d’exercice restent lisibles et modifiables dans le JSON ; pas d’anti-triche, de verrouillage des cartes, d’indices, de notation partielle ni de soumission.
- Le mot de passe protège l’interface, pas le fichier.
- Les cartes graphiques ne sont pas transpilables.
- C, C++ et Java restent indisponibles ; le modèle objet n’est pas défini.
- Bundle JavaScript principal supérieur à 500 ko.
