# Sapphire 3 — 0.1.0-beta.8

Bêta centrée sur l'exécution continue, le dashboard exporté et la vitrine publique multilingue. Le format workspace reste en version 3 ; aucune migration supplémentaire n'est introduite.

## Nouveautés

- **Run live par défaut** : un interpréteur coopératif exécute le programme par tranches, sans budget total, avec Pause/Reprise/Stop et un curseur de vitesse de 1 à 100. Les entrées des boutons sont appliquées entre deux frames, sans relancer le programme. Le **Run borné** reste disponible pour précalculer une trace finie.
- **Boutons d'entrée interactifs** : les boutons sont liés à une fonction `onClick(bool)`, avec l'exemple **Simple → Input** (deux boutons et une LED) et les callbacks dans le dashboard.
- **Dashboard exporté enrichi** : disposition bento à deux colonnes, panneaux déplaçables, redimensionnables, masquables et restaurables, thèmes sombre/clair de l'application, mini-carte des modules et classes avec leurs dépendances, contrats regroupés par module, commentaires avec formules KaTeX, XY plot Mafs, oscilloscope uPlot, Run live, Run borné et Run autonomous, Pause/Stop et vitesse réglable.
- **Exemples supplémentaires** : système solaire képlérien, deux boutons avec LED et cinq créations de vitrine (Neon rose, Harmonic studio, Chirp ribbon, Wave packet, Orbital trails), avec modules Math dédiés.
- **Corrections ciblées des classes** : lectures non initialisées refusées, méthodes liées utilisables comme callbacks ou attributs fonction, récepteur évalué avant les arguments et propre type remappé lors de la duplication.
- **Vitrine publique** : accueil traduit dans les huit langues de l'application, anglais par défaut, préférence mémorisée localement et direction RTL pour l'arabe ; sélecteur de langue, GitHub et recherche regroupés dans l'en-tête ; bouton de recherche présent dès le chargement pour éviter tout décalage de la navbar ; téléchargements alignés sur cette bêta.

## Installation

- **Windows** : `Sapphire3-0.1.0-beta.8-windows-setup.exe` ou `Sapphire3-0.1.0-beta.8-windows.zip`.
- **Linux x64** : `Sapphire3-0.1.0-beta.8-linux-x64.tar.gz`, puis `./Sapphire3`. WebKitGTK 4.1 requis.
- **Linux ARM64** : `Sapphire3-0.1.0-beta.8-linux-arm64.tar.gz`.
- **macOS** : `Sapphire3-0.1.0-beta.8-macos-universal.zip`, puis `Sapphire 3.app`. macOS 11 ou ultérieur requis.

## Compatibilité et limites

- Workspace version 3 inchangé ; les fichiers versions 1 et 2 sont toujours migrés à la lecture.
- Les paquets **Linux et macOS sont construits mais n'ont pas été exécutés** sur leur système cible. Leur prise en charge réelle doit être vérifiée avant d'être annoncée comme validée.
- Windows n'est pas signé et macOS n'est pas notarié : des avertissements système peuvent apparaître. Aucun certificat n'est configuré.
- L'installateur Windows est construit ; l'installation et la désinstallation n'ont pas été rejouées pour cette bêta. Le lancement vérifié concerne le ZIP portable extrait.
- Pas de nouvelle campagne exhaustive des dialogues natifs ni de l'accessibilité.
- C, C++ et Java restent indisponibles ; les cartes graphiques et les classes ne sont pas transpilées.
