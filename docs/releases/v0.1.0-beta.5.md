# Sapphire 3 Beta 0.1.0-beta.5

Mise à jour corrective de la bêta Windows, regroupant les améliorations d’accessibilité et le nouveau menu de création depuis `0.1.0-beta.4`. Le format workspace reste en version 2 ; aucune migration supplémentaire n’est introduite.

## Nouveautés

- **Menu de création réorganisé** : les cartes sont regroupées en trois colonnes — **Programmation**, **Widgets** et **Annotations** — avec un champ de recherche en tête. Le filtrage ignore casse et accents et porte sur le libellé, le type ou la catégorie. Le menu reste utilisable au clavier : focus dans la recherche, flèches vers les cartes, `Entrée` pour activer le premier résultat, `Échap` pour fermer. Repli en une colonne sur une fenêtre étroite.
- **Accessibilité** : lien d’évitement vers le canvas, tableaux masqués pour les valeurs des BarChart et Heatmap, `role="img"` sur l’écran, retour de focus après les confirmations, cibles de 24×24 pour les contrôles compacts, zone défilante des paramètres focalisable, suppression des régions dupliquées de l’arbre logique et annonces de simulation limitées aux changements d’état.
- **Documentation** : `docs/ACCESSIBILITY.md` devient le référentiel WCAG 2.2 A/AA avec matrice, preuves, limites et procédure de rejeu.

## Installation et mise à jour

1. Télécharger `Sapphire3-0.1.0-beta.5-windows.zip` ou `Sapphire3-0.1.0-beta.5-windows-setup.exe`.
2. Pour le ZIP : extraire dans un dossier accessible en écriture, puis lancer `Sapphire3.exe`.
3. Pour l’installateur : installation par utilisateur, sans droit administrateur.

Windows 10/11 avec WebView2 est requis ; Node.js n’est pas nécessaire. La mise à jour intégrée propose cette préversion après publication, avec confirmation et vérification de la taille et du SHA-256.

> Le paquet est **non signé** : SmartScreen peut afficher un avertissement. Ne pas le présenter comme une version signée.

## Limites connues

- Version **bêta**.
- Bordures de composants encore sous le rapport de contraste 3:1 ; identité visuelle conservée.
- Pas encore d’alternative au clic seul pour déplacer ou redimensionner spatialement les modules, annotations et panneaux.
- Erreurs de formulaire non reliées au champ précis.
- Tests NVDA/Narrator et fenêtre WebView2 non exécutés dans cet audit.
- Les cartes graphiques ne sont pas transpilables.
- C, C++ et Java restent indisponibles ; le modèle objet n’est pas défini.
- Bundle JavaScript principal supérieur à 500 ko.
