Douze dashboards exportés, interactifs

Chaque cadre ci-dessous est un fichier dashboard.html réellement produit par Settings → Export → Web dashboard, pas une capture. Les panneaux sont déplaçables, les thèmes et les langues sont réglables, et les commandes exécutent le vrai moteur embarqué. Le thème choisi dans Settings est proposé par défaut ; chaque visiteur peut ensuite changer librement de thème et de luminosité, son choix étant mémorisé localement. Rien ne démarre avant un clic sur Run live, Run ou Run autonomous.

Les douze exemples

Générés depuis les exemples locaux

La sélection réunit le système solaire, les deux boutons d'entrée avec LED, cinq démos visuelles déjà présentes et cinq créations dédiées. Elle couvre géométrie 3D, rosaces progressives, signaux, croissance cellulaire, trajectoires et entrées interactives. Run live exécute l’interpréteur coopératif continu ; Run autonomous rejoue la trace pour les programmes finis et lance le live continu pour les exemples SP3_LIVE. Arrêtez puis relancez pour renouveler les données. Les boutons d'entrée appellent la fonction liée avec leur état ; le toggle la répète toutes les 500 ms. Widgets représentés : Screen, XY plot, Oscilloscope, ProgressBar, Gauge, LED, RGB LED et boutons d'entrée.

Rester à jour

Après chaque changement du dashboard

Ces fichiers sont des artefacts générés, pas des maquettes. La commande suivante les reconstruit depuis les exemples locaux et le code courant du dashboard : 

pnpm dashboards:build

La CI régénère les douze fichiers et refuse une pull request si le résultat diffère de ce qui est commité. Relancer la commande après tout changement qui impacte l’export : widgets, commandes d’exécution, thèmes, langues, mise en page, polices ou pied de page.
