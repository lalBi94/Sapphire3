Dix dashboards exportés, interactifs

Chaque cadre ci-dessous est un fichier dashboard.html réellement produit par Settings → Export → Web dashboard, pas une capture. Rester à jour

Après chaque changement du dashboard

Ces fichiers sont des artefacts générés, pas des maquettes. La commande suivante les reconstruit depuis les exemples locaux et le code courant du dashboard : 

pnpm dashboards:build

La CI régénère les dix fichiers et refuse une pull request si le résultat diffère de ce qui est commité. Relancer la commande après tout changement qui impacte l’export : widgets, commandes d’exécution, thèmes, langues, mise en page, polices ou pied de page.
